# Kbd

Eine Taste oder Tastenfolge, in Menüs, Tooltips, Befehlspalette und Tastenübersicht.

- `mono-small` mit Rahmen `control-border`, unten 2px (Tastenkappe).
- macOS zeigt ⌘, Windows und Linux „Strg+“. Zwei Stufen als zwei Kappen nebeneinander, in Menüs ohne „dann“.
- Belegung: siehe README, Abschnitt Tastatur.
