# ActivityRail

Die senkrechte Leiste links mit den fünf Bereichen: Projekt, Katalog, Bus, Prüfung, Werkzeuge.

- Breite `rail-w`; Einträge 54px mit Icon (18px) und Beschriftung in `micro`.
- Aktiver Bereich `accent` auf `accent-weak`. Zähler (Befunde der Prüfung) als Marke oben rechts in `warn`.
- Tasten ⌘1–⌘5 springen direkt in den Bereich.
- Am Phone wird die Leiste zur Tab-Leiste unten (Projekt, Bus, Prüfung, Mehr).
