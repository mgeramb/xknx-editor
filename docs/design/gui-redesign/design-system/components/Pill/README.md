# Pill

Klickbarer Zustand in der Kopfleiste: ausstehende Programmierungen, Verbindung, laufende Aufnahme.

- Immer antippbar: Die Ausstehend-Pille öffnet die Liste der Geräte, die Verbindungspille das Verbindungsmenü.
- Ausstehend in `warn` auf `warn-weak`, Aufnahme in `danger` auf `danger-weak`, Verbindung neutral mit StatusDot.
- Zahl und Wort mit richtigem Plural („1 Gerät ausstehend“, „5 ausstehend“), nie „Gerät(e)“.
