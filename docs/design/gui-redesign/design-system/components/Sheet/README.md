# Sheet

Blatt von unten für Auswahl und Details auf Tablet (hoch) und Phone.

- Radius `radius-xl` oben, Schatten `shadow-sheet`, darunter `scrim`. Griff oben; nach unten wischen oder daneben tippen schließt es.
- Ein Thema je Blatt: Programmieren, Parameterseite wählen, ein Kommunikationsobjekt, der Inspektor.
- Optionen als große Flächen (52px) mit Radio-Kreis, gewählte in `accent-weak`.
- Am Desktop wird daraus ein Menü, Popover oder Dialog.
