# TreeRow

Eine Zeile im Navigator: Gerät, Gruppenadresse oder Bereich.

- Adresse vorn in `mono` und `muted`, Name in `body`, StatusDot rechts.
- Gewählt: Fläche `sel` und 3px-Strich links in `accent`.
- Gruppenköpfe (Räume, Linien, Hauptgruppen) in `label-caps`.
- Höhe `row-h` (28px), bei Touch `row-h-touch` (44px).
- Lange Namen enden mit „…“, der volle Name steht im Tooltip.
