# KoCard

Ein Kommunikationsobjekt als Karte, wo die KO-Tabelle keinen Platz hat (Phone, schmale Panels).

- Kopf: Nummer in `mono`, Name in `body-strong`, Flags in Kurzform rechts.
- Darunter die GaChips, die sendende zuerst. Ohne Verknüpfung ein Hinweis in `muted`.
- Antippen öffnet das Objekt als Sheet mit Verknüpfen, Trennen und Wert lesen.
