# StatusDot

Kleines Zustandszeichen hinter einem Gerät im Navigator und in dichten Listen.

- Die vier Zustände unterscheiden sich in der **Form**, nicht nur in der Farbe: gefüllter Kreis (`status-programmed`), halb gefüllter Kreis (`status-pending`), Kreis mit Kreuz (`status-error`), leerer Ring (`status-unknown`). So sind sie auch bei Rot-Grün-Schwäche und in Graustufen lesbar.
- 10px, rechtsbündig in der Zeile. Tooltip und Inspektor nennen den Zustand in Worten.
