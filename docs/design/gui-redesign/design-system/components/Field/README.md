# Field

Label und Eingabe in einer Zeile, außerhalb des Parameter-Editors (Inspektor, Dialoge, Einstellungen).

- Label links in `body`, Eingabe rechts mit Rahmen `control-border`; Einheit in `muted` im Feld rechts.
- Unter 560px steht das Label über dem Feld (wie im Einstellungsfenster).
- Geänderte, noch nicht programmierte Werte: 3px-Strich links in `warn`.
- Die Felder im Parameter-Editor zeichnet die Gerätekonfiguration; dort gilt nur Abstand und Zeilenhöhe dieses Systems.
- Suchfelder auf `sub` mit Lupe; die Befehlspalette zeigt ihr Kürzel rechts.
