# Toast

Kurze Rückmeldung nach einer Aktion, die sonst unsichtbar wäre.

- Oben mittig im Arbeitsbereich, 2s, auf `overlay`. Nach einer Taste steht die Taste davor.
- Ein Satz, Sentence case, sagt was passiert ist („Programmiert: 1.1.16“). Fehler mit Ursache und Abhilfe gehören in einen Dialog oder den Inspektor, nicht in einen Toast.
