# Tabs

Reiter für verschiedene Inhalte desselben Objekts, z. B. Parameter, Kommunikationsobjekte und Info eines Geräts.

- Aktiver Reiter: Text `accent`, 2px-Strich unten in `accent`, `body-strong`.
- Reiter werden nicht ausgeblendet oder abgedockt; dafür gibt es die Zonen.
- Am Phone werden sie zu Segmenten.
