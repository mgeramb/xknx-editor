# GaChip

Eine Gruppenadresse an einem Kommunikationsobjekt, in Tabellen, Karten und im Inspektor.

- Adresse in `mono` auf `accent-weak`, Text `accent`. Die **sendende** Adresse trägt zusätzlich einen 1-px-Rahmen in `accent` und steht vorn.
- Tooltip: Name der Gruppenadresse und DPT. Klick wählt die Gruppenadresse im Inspektor.
- Ohne Verknüpfung steht „Nicht verknüpft“ in `muted`, nie ein leerer Platz.
