# WhichKey

Das Auswahlfenster nach der ersten Stufe einer Tastenfolge (⌘G, ⌘D, ⌘L, ⌘K).

- Erscheint nach 0,4s unten mittig über der Statusleiste, auf `overlay` mit Text `overlay-text`.
- Je Eintrag die Taste und der Befehl, der Buchstabe im Wort unterstrichen. Einträge sind antippbar.
- Gleichzeitig zeigt die Statusleiste „⌘G … Gehe zu“, sofort und ohne Verzögerung.
- Esc oder 3s ohne Taste brechen ab; eine Taste ohne Belegung bricht mit Meldung ab.
