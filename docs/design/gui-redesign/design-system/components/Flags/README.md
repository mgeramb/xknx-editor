# Flags

Die sechs Flags eines Kommunikationsobjekts: K Kommunikation, L Lesen, S Schreiben, Ü Übertragen, A Aktualisieren, I Initialisierung.

- Immer alle sechs in fester Reihenfolge, gesetzte in `accent` auf `accent-weak`, nicht gesetzte als leerer Rahmen. So bleibt die Spalte ausgerichtet.
- In dichten Tabellen am Phone die Kurzform in `mono-small` („K·S··“), Punkt für nicht gesetzt.
- Englische Oberfläche: C R W T U I. Der Tooltip nennt die Flags ausgeschrieben.
