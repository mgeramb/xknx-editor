# Segmented

Umschalter für zwei bis vier gleichrangige Sichten auf denselben Inhalt.

- Einsatz: Sicht des Navigators (Gebäude | Topologie | Gruppenadressen), Filter der KO-Tabelle.
- Grund `sub`, gewähltes Segment `panel` mit leichtem Schatten und `body-strong`.
- Mehr als vier Optionen oder lange Texte: Drop-down statt Segmente.
