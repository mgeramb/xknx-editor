# SplitButton

Primärer Knopf mit einer Standardaktion links und der Auswahl weiterer Umfänge rechts.

- Einsatz: „Programmieren ▾“ im Gerätekopf. Links startet der zuletzt gewählte oder empfohlene Umfang (Partiell), rechts öffnet ein Menü mit allen Umfängen: Partiell, Partiell: Parameter, Partiell: Gruppenkommunikation, Physikalische Adresse, Vollständig, Entladen.
- Das Menü zeigt die Tastenfolge jeder Aktion (siehe Kbd).
- Auf dem Phone wird daraus ein Knopf „Programmieren…“, der ein Blatt öffnet (siehe Sheet).
