# Menu

Menüs, Kontextmenüs und das ⋯-Menü eines Objekts.

- Einträge in Title Case; ein Eintrag, der einen Dialog öffnet, endet auf „…“.
- Rechts die Tastenfolge als Kbd. Was gerade nicht geht, steht in `muted` mit Grund dahinter, statt zu fehlen.
- Zerstörende Einträge in `danger`, durch eine Linie abgesetzt, ganz unten.
- Schatten `shadow-popover`, Radius `radius-md`.
